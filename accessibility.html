Accessibility

Using this site

This site is built to be usable with a keyboard, a screen reader, at high zoom, and without animation. Where it falls short, the firm would like to know.

Last updated 8 August 2026

Aiming at WCAG 2.2 level AA. That is the standard this site is built against. It has not yet been through a formal independent audit, so this statement describes what has been done and what is known to be outstanding rather than claiming full conformance.

What has been done

  • Keyboard — every link, button, form field and accordion can be reached and operated with a keyboard alone. A visible focus outline shows where you are.
  • Skip link — a "skip to main content" link is the first thing in the tab order on every page, so you do not have to tab through the navigation each time.
  • Structure — pages use real landmarks and a single, ordered heading hierarchy, so screen reader users can navigate by region and by heading.
  • Accordions — the frequently asked questions use the browser's native details element rather than scripted widgets, so they work with assistive technology and without JavaScript.
  • Forms — every field has a visible, permanently associated label. Nothing relies on placeholder text alone, and errors are described in words rather than by colour.
  • Live results — the deadline checker announces its result to screen readers as it updates.
  • Motion — the scroll reveal and all transitions are switched off when your system is set to reduce motion. Content never depends on animation to appear.
  • Colour — text and interface colours are drawn from a fixed palette chosen for contrast, and colour is never the only means of conveying information.
  • Zoom and reflow — the layout is fluid and reflows to a single column, so it remains usable at high zoom and on small screens without horizontal scrolling.
  • No storage, no cookies, no timeouts — nothing expires, nothing is remembered, and there is no time pressure to complete a form.
  • Works without JavaScript — all content and every link is available with JavaScript disabled. Only the deadline checker and the multi-step form need it.

Known issues

Being straight about the gaps is more useful than a claim of perfection:

  • No independent audit yet. The site has been built and tested against WCAG 2.2 AA but has not been formally audited by a third party.
  • Text re-renders once the typefaces load. Pages paint immediately in your system's fonts and swap to the site's own a moment later, which shifts the layout slightly. The fonts are served from this site rather than a third party, so there is no external connection to wait on, but on a slow link you may still see the change.
  • The multi-step case review needs JavaScript. If you cannot use it, the same information can be given by telephone or by email, and no part of your matter depends on having used the form.
  • PDFs and documents. Documents the firm sends you in the course of a matter are not covered by this statement. If you need one in a particular format, ask.

If you need something in another format

Correspondence can be provided in large print, in plain text, or by telephone instead of in writing. Meetings can be held by telephone or video. Tell the firm what works for you at the start of your matter, or at any point afterwards — it does not need to be justified.

Reporting a problem

If you find something on this site you cannot use, email jc@andrewsmonroe.co.uk or call 07521 844993. It helps to say what page you were on, what you were trying to do, and what browser or assistive technology you were using — but a one-line description is better than nothing.

If you are not satisfied with the response, the firm's complaints procedure applies in the same way as it does to any other service issue.

Technical detail

This site is plain HTML, CSS and a small amount of JavaScript. There is no framework, no icon font, no third-party widget and no embedded media. That is a deliberate accessibility and performance decision as much as a technical one: the fewer moving parts there are, the fewer things there are to break for someone using the site in a way we did not anticipate.

Tell the firm about a barrier

If any part of this site stopped you doing what you came to do, say so. If you need information from it in another format, ask — that is not a special request.
